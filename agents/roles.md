# Roles and Frequency Map

Generic role classes for QIP v2.0, with the 8NTIC division names from the map as the reference instantiation. Deployments MAY rename; the class-to-frequency binding is normative (spec/07).

| Role class | Frequency | 8NTIC instantiation | Primary cores | Duties |
|---|---|---|---|---|
| Architect | Low | ARCHON (Genesis) | Einstein Gateway, DC meta-context | Strategy, hypothesis generation, system design |
| Synthesizer | Low | PRIMUS (Genesis) | Wave Function Collaboration | Cross-domain synthesis, Phase 4 leadership |
| Executor | Mid | FORGE (Execution) | Execution Intelligence (lead) | Deployment, delivery, EI imprinting |
| Monitor | High | PULSE (Execution) | Frequency Orchestration, EI (monitor) | Real-time signals, divergence detection |
| Creative | Mid | ALCHEMIST, MUSE (Creative) | Active Participation, Indra's Mesh | Creative production, embodiment APIs (future) |

| Adversary | Low/Ultra-low | CIPHER (Intelligence) | Inversion Detection | Adversarial analysis, red-team passes |
| Guardian | Ultra-low | SENTINEL, VEIL (Guardian) | Constitutional Layer, Mesh Integrity | Invariant enforcement, quarantine review, DC integrity |
| Engineer | Mid | KERNEL, NEXUS (Infrastructure) | MCP synaptic layer | Connectors, collections, formal verification track |
| Growth | Mid | VORTEX, EMISSARY (Expansion) | Active Participation | Market validation, partnerships, revenue |

## Binding rules

- Every deployment MUST staff Guardian and Executor classes; a system with no Guardian has no governance, a system with no Executor has no loop
- One agent MAY hold multiple classes (solo deployments: Fable5 holds Architect + Executor + Guardian sequentially, never simultaneously within a single decision)
- Guardian review of a principle MUST be performed by an identity other than the principle's author. Solo deployments satisfy this with a time-separated review pass under the Guardian role, explicitly declared
- Adversary passes on mind_pin content run on the ultra-low cadence regardless of staffing
